
# لَمْعَة | LAM'A

متجر إلكتروني عربي تجريبي لعرض الساعات والعطور والإكسسوارات.

## فكرة المشروع
إنشاء متجر إلكتروني بسيط وأنيق، يدعم اللغة العربية،
ويتيح للزوار استعراض المنتجات وتجهيز استفسارات
عنها عبر واتساب.

## التقنيات المستخدمة
- HTML5
- CSS3
- JavaScript
- CSS Grid
- Flexbox
- LocalStorage
- WhatsApp Links

## مميزات المتجر
- تصميم عربي RTL.
- واجهة متجاوبة مع الهاتف والكمبيوتر.
- عرض صور المنتجات.
- سلة مشتريات تفاعلية.
- زيادة الكميات ونقصانها.
- حذف المنتجات من السلة.
- حفظ السلة محليًا.
- تجهيز استفسار عن المنتجات عبر واتساب.

## حالة المشروع
نسخة تجريبية تعليمية قيد التطوير.
المنتجات والأسعار لم تُعتمد للبيع الفعلي.

## تشغيل المشروع
افتح ملف index.html في المتصفح،
أو استخدم Live Server داخل VS Code.

## التطوير المستقبلي
- إضافة منتجات وأسعار حقيقية.
- تحسين تجربة المستخدم.
- إضافة إدارة للمنتجات والطلبات.
- تطوير Backend وقاعدة بيانات عند الحاجة.
